# Milo pet playtest

Browser QA uses Chromium 138 and an embedded game surface inside an 844px outer viewport. The baseline captured three failed checks: missing Pet Studio header control, missing roaming Milo canvas, and the old welcome tagline. Evidence: `tests/pet-artifacts/baseline-results.json`.

The final integration run on 2026-10-14 at 23:10 UTC passed **20 of 20 checks**, with no uncaught browser errors. Evidence: `docs/testing/pet-results.json` (generated by `tests/pet-browser.mjs`).

| Coverage | Observed result |
| --- | --- |
| Embedded layout | Header buttons do not overlap; studio and wardrobe controls fit 320×520, 390×610 and 430×650 surfaces |
| Accessible modal | Shift+Tab remains inside the studio; Escape closes it |
| Actual character | A real touch changes reaction state and rendered canvas; the 56px sprite hit target stays within content; an actual showroom hop completes |
| Cosmetic purchase | Lavender Cloud deducts 25 Gems once and remains equipped after reload |
| Preview | Mint preview changes actual green pixels in the canvas without spending Gems or changing ownership |
| Full wardrobe | An isolated 200-Gem fixture buys Bunny Ears, Sparkly Eyes and Tiny Crown for 115 Gems; all three styles and the remaining wallet survive reload |
| Care | Buying five treats costs 15 Gems; rapid repeat feeding consumes only one treat during cooldown |
| Name/save | Pixel and the complete pet state survive reload |
| Visibility | Pet appears on home/showroom, hides for shop/awards/settings/toys/chat/studio, and returns after chat closes |
| Motion | Both the in-game reduced-motion setting and the system preference independently stop roaming while game navigation remains usable |

Local screenshots under `tests/pet-artifacts/` include `surface-studio-320.png`, `surface-reaction.png`, `surface-showroom-hop.png`, `styled-pet-studio.png`, and `styled-pet-restored.png`. Additional `styled-showroom.png` and `styled-showroom-hop.png` render the same verified purchased-style combination from an explicit visual fixture. The latter capture an actual procedural hop, not a composited character.

Initial integration harness labels were aligned with the final catalogue names and semantic tab roles. The modal keyboard regression and low-platform hop clipping were corrected before the final passing run.

This emulator does not measure physical phone performance or haptic/audio quality. Fixture Gems remain isolated to browser QA.
